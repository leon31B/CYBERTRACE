📖 Broken Access Control — Educational Briefing CWE-284 / OWASP A01:2021 #1 Risk
1. What is it?

Broken Access Control occurs when users can access resources, files, or functions outside their designated permissions.

2. Why does it happen? (Root Cause)

Relying on client-side "security through obscurity" (hiding buttons/links in HTML) instead of enforcing server-side authorization checks on every endpoint.

3. Impact

Vertical privilege escalation (e.g. Analyst accessing executive files or Admin databases) and horizontal privilege escalation (accessing another user's private data).

4. Prevention (Mitigation)

Server-side Role-Based Access Control (RBAC decorators). Every route checks session.get('role') on the server and rejects unauthorized requests with HTTP 403 Forbidden.
