📖 Cross-Site Scripting (XSS) — Educational Briefing CWE-79 / OWASP A03:2021
1. What is it?

Cross-Site Scripting (XSS) occurs when malicious HTML markup or scripts are injected into web applications and delivered to other users' browsers.

2. Why does it happen? (Root Cause)

Unsafe rendering of user input without proper HTML output encoding (e.g. using the Jinja2 |safe filter on untrusted input).

3. Impact

Session hijacking, page defacement, unauthorized actions performed on behalf of the victim, or credential harvesting.

4. Prevention (Mitigation)

Contextual HTML entity encoding (Jinja2 default autoescaping), converting special characters like < and > into harmless text entities (&lt; and &gt;).
