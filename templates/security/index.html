💉 SQL Injection (SQLi) DEMONSTRATED & MITIGATED

Occurs when untrusted user input is directly concatenated into database query strings, allowing attackers to alter the SQL logic structure.

Attack Surface: Search forms, query parameters, authentication filters
Severity / Risk: CRITICAL (Data exfiltration, auth bypass)
Secure Defense: Parameterized queries (prepared statements via SQLite ? placeholders)
Open SQLi Lab →
⚡ Cross-Site Scripting (XSS) DEMONSTRATED & MITIGATED

Occurs when malicious script tags or JavaScript payloads in user input are rendered raw into the HTML DOM without sanitization.

Attack Surface: Investigation notes, user profile names, feedback fields
Severity / Risk: HIGH (Session hijacking, defacement)
Secure Defense: Contextual HTML entity escaping (Jinja2 default escaping)
Open XSS Lab →
🔄 Cross-Site Request Forgery (CSRF) DEMONSTRATED & MITIGATED

Occurs when an external site tricks an authenticated browser into submitting unauthorized state-changing POST requests.

Attack Surface: Profile updates, case note submissions, evidence logging
Severity / Risk: MEDIUM (Unauthorized configuration alterations)
Secure Defense: Cryptographic Synchronizer Token Pattern verified on POST
Open CSRF Lab →
🔐 Broken Access Control (RBAC) DEMONSTRATED & MITIGATED

Occurs when an application relies only on client-side UI hiding rather than enforcing authorization checks at the backend endpoint.

Attack Surface: Admin endpoints, direct object URL parameters, API routes
Severity / Risk: CRITICAL (Privilege escalation, unauthorized admin access)
Secure Defense: Server-side role verification decorator rejecting with HTTP 403
Open Access Control Lab →
📄 Sensitive Information Disclosure DEMONSTRATED & MITIGATED

Occurs when applications leak internal filesystem paths, database file locations, API secrets, or raw Python stack traces to untrusted users.

Attack Surface: 500 internal error pages, unhandled exceptions, verbose debug modes
Severity / Risk: MEDIUM (Reconnaissance aid for targeted exploitation)
Secure Defense: Custom production error handlers, server-only logging, credential redaction
