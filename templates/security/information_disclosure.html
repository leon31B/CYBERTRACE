📖 Sensitive Information Disclosure — Educational Briefing CWE-200 / OWASP A05:2021
1. What is it?

Sensitive Information Disclosure occurs when an application exposes technical metadata, internal filesystem paths, debug stack traces, or configuration keys to untrusted end users.

2. Why does it happen? (Root Cause)

Leaving debug modes enabled in production, improper exception handling, or printing raw error tracebacks directly to the client browser.

3. Impact

Adversaries gather precise intelligence about underlying server architecture, software versions, directory layouts, and database paths to plan targeted attacks.

4. Prevention (Mitigation)

Production-grade error handling (@app.errorhandler(500)) serving sanitized generic error templates, keeping detailed logs strictly on internal server logs, and masking credentials.

✅ SECURE IMPLEMENTATION: PRODUCTION ERROR HANDLING

Standard defensive architecture: All unhandled exceptions are caught by Flask's @app.errorhandler(500), logging stack traces to server logs while returning a generic, safe response to the user.

🛡️
Internal Incident Logged

INCIDENT REFERENCE: CT-INC-99420-LOCAL
Defensive Measures Enforced:
• No Stack Traces: End users never see Python file lines or internal exceptions.
• No Hardcoded Secrets: Secret keys loaded from environment variables.
• Masked Passwords: Even database viewers display hashes or masks.
• Server Console Logging: Critical diagnostics routed to administrative logging streams.
🔍 Code Comparison: Defensive Exception Handling
❌ VULNERABLE: Direct Exception Exposure
@app.route('/query')
def query():
    try:
        do_database_operation()
    except Exception as e:
        # Exposes internal exception and paths to user!
        return str(e), 500
✅ SECURE: Centralized Error Handler
@app.errorhandler(500)
def internal_server_error(e):
    # Logs full traceback internally on server console
    logger.error("Unhandled error: %s", e, exc_info=True)
    # User receives only a clean, sanitized template
    return render_template('errors/500.html'), 500
